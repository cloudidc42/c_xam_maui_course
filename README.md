# หลักสูตร C# Xamarin/.NET MAUI ครบวงจร
## จากระดับพื้นฐาน สู่ระดับมืออาชีพและระดับโลก

---

## เกี่ยวกับหลักสูตร

หลักสูตรนี้ออกแบบมาเพื่อสอนการพัฒนาแอปพลิเคชัน Cross-platform ด้วย C# โดยใช้เทคโนโลยี Xamarin และ .NET MAUI ตั้งแต่พื้นฐานจนถึงระดับมืออาชีพ

### เป้าหมายหลักสูตร
- เรียนรู้ C# ตั้งแต่พื้นฐาน
- พัฒนาแอปบน iOS, Android, Windows, macOS ด้วย code เดียว
- เข้าใจสถาปัตยกรรม MVVM, Clean Architecture
- สร้างแอประดับ Production จริง

## วิธีใช้หลักสูตรนี้

1. เรียนตามลำดับ Part 01 ถึง Part 100
2. ทำแบบฝึกหัดในแต่ละ Part ให้ครบ
